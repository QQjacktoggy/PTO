Start with [README_START_HERE.md](README_START_HERE.md), then read:

1. [AGENTS.md](AGENTS.md)
2. [ADAPTIVE_QUANT_MASTER_PLAN.md](ADAPTIVE_QUANT_MASTER_PLAN.md)

The initial repository contains the reviewed handoff plan, configuration
contracts, schemas, and Phase 0–14 prompts. It intentionally contains no
exchange credentials, live-order integration, Testnet connection, or market
data. Development must begin at Phase 0 and follow the gates defined in the
project documents.
